# Футбольные котики SIGNAL

Файл: [football-cats-v1.png](../../client/public/art/football-cats-v1.png). Создан встроенным image_gen по исходным cat-PM.png и cat-hero-atlas-1.4.png соседнего SIGNAL CATS. CLI/API-ключ и внешние сервисы игры не используются.

Ресурс 1254×1254, PNG с настоящим прозрачным фоном, 1 203 985 байт. Атлас 4×4; целочисленные границы ячеек вычисляются через floor, поскольку размер изображения не делится на 4. В runtime одна текстура, 16 кадров. Отдельные части персонажа не дорисовываются поверх bitmap.

Синие: кадры 0–7, красные 8–15. В каждой группе: ожидание, две фазы бега, удар, подготовка/восстановление, две фазы скольжения, празднование. Дополнительные плавные покачивания выполняются PixiJS; физический круг от анимации не меняется. Оригинальные референсы не нужны при запуске — итоговый ресурс включён в проект.

Исходный промпт встроенного инструмента:

> Use case: stylized-concept. Asset type: production 2D football character sprite atlas for PixiJS. The two reference images define the SAME SIGNAL mascot identity: rounded navy cat, white muzzle, huge shiny dark eyes, triangular navy ears with white inner ears, rounded paws. Preserve this recognizable face and silhouette exactly. Replace ALL helmet/cape/superhero clothes with simple football jersey and shorts, white small chest stripe, dark paws. Create ONE square sprite sheet, exactly 4 columns x 4 rows of equally sized cells, no gutters and no visible cell borders. All 16 characters fully inside their cells with ample transparent margin, matching scale, consistent ground/feet anchor at 85% of each cell height; 3/4 front-facing readable friendly face. Navy fur and white muzzle remain identical across all poses. FIRST TWO ROWS BLUE uniform (#0695D7), LAST TWO ROWS RED uniform (#FF4758). Row 1 left to right: blue idle standing, blue running left foot forward, blue running right foot forward, blue football kick with one extended foot. Row 2: blue aiming/crouched preparation, blue slide tackle left leg extended without falling, blue slide tackle second pose, blue celebration both paws up. Row 3: red idle standing, red running left foot forward, red running right foot forward, red football kick with one extended foot. Row 4: red aiming/crouched preparation, red slide tackle left leg extended, red slide tackle second pose, red celebration both paws up. Professional crisp clean smooth cartoon illustration matching the reference, strong silhouette, soft minimal shading. Ground plane only implied by paws, no drawn shadows outside the figures. All faces look toward the viewer, no rear-view poses and no upside down rotation. True transparent alpha background throughout. No text, no labels, no numbers, no symbols, no logo, no ball, no background scene, no grid lines, no borders, no checkerboard pattern. Exactly sixteen equal cell poses, one figure per cell, aligned so the runtime can divide the image into a regular 4x4 grid.

UI-иконки движения, удара, подката, мяча, копирования и выхода выполнены как SVG в client/src/ui/icons.ts. Это отдельный набор в одном стиле, не эмодзи.
