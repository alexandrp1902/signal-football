# SIGNAL CATS FOOTBALL

[Играть в браузере](https://alexandrp1902.github.io/signal-football/)

Футбол с котиками для компьютера и телефона. Можно тренироваться одному или пригласить друга в комнату для игры 1×1.

## Как играть

1. Введите ник и нажмите «Создать тренировку».
2. Подойдите к мячу, чтобы начать ведение.
3. Поделитесь приглашением или четырёхзначным кодом комнаты.
4. Для матча нажмите «Начать матч». После результата можно начать ещё один матч или вернуться к свободной игре.

На компьютере: WASD или стрелки — движение, курсор — направление удара, удержание левой кнопки мыши — заряд, отпускание — удар с мячом или подкат без мяча. Escape отменяет подготовку.

На телефоне: левый стик управляет движением, правый задаёт направление и заряд действия. Отпустите правый стик для выполнения; возврат в его центр отменяет подготовку.

## Что реализовано

- Общий мяч, ведение, заряжаемый удар и подкат.
- Столкновения игроков без проталкивания и сбивания с ног.
- Счёт, отсчёт перед матчем, таймер и повторная игра.
- Поворот персонажа в восемь направлений, бег и замах перед ударом.
- Управление с клавиатуры, мыши и двух независимых сенсорных стиков.

Комнаты временные. При разрыве соединения место освобождается; восстановление прежней игровой сессии пока не поддерживается.

## Локальная разработка

Нужны Node.js 24.x, .NET SDK из [global.json](global.json) и PowerShell. Команды выполняются из корня репозитория:

~~~powershell
dotnet restore server/CatsFootball.sln --locked-mode
npm --prefix client ci
powershell -NoProfile -ExecutionPolicy Bypass -File tools/dev.ps1
~~~

Откройте http://localhost:5174. Скрипт запускает локальные клиент и сервер; Ctrl+C завершает созданные им процессы. Зависимости от соседних проектов отсутствуют.

## Проверки

~~~powershell
npm --prefix client test
npm --prefix client run build
dotnet test server/CatsFootball.sln -c Release
node tools/check-publication.mjs
~~~

При работающем локальном сервере доступны дополнительные проверки:

~~~powershell
node tools/smoke.mjs
npm --prefix client run test:browser
~~~

Браузерные тесты используют Google Chrome и временные профили.
